# Первое сообщение в WhatsApp

Эти же тексты в трёх вариантах формулировки вшиты в страницу-очередь (`queue/index.html`): она сама подставляет название и город.

## Первое сообщение

Сегмент: компании из 2ГИС **без сайта** (парсер отдаёт и WhatsApp, и флаг наличия сайта).

```
Здравствуйте! Это [Имя]. Искал в 2ГИС [натяжные потолки] в [Казани] и наткнулся на вас: отзывы хорошие, а сайта нет.

Понимаю, что неожиданно, но я уже собрал для «[Название]» сайт. Показать?
```

Почему так:

- **«Уже собрал»** — это SMS-шаблон Майка почти дословно (по его словам, 100 сообщений → ~30 ответов → 3 встречи) и тот же скрипт «у меня уже есть результат», который в твоём `offer_profile` стоит первым по конверсии (13,4% у Karston Fox). Цифры — заявления авторов на рынке США, не прогноз для тебя.
- **«Искал в 2ГИС… сайта нет»** — персонализация по Хормози: холодное касание должно выглядеть как тёплое. И это правда, а не выдуманный «личный опыт».
- **Одна мысль и один вопрос** — правило методички: одна боль → решение → простой шаг. Ни цены, ни списка фич, ни рассказа о себе.
- **Без ссылки** — как у Кая и Майка: ссылку не даём, ведём на показ. Плюс, по моему опыту (в твоих материалах этого нет), ссылка в первом сообщении с нового номера повышает риск жалобы и бана в WhatsApp.
- **Сайт здесь — приманка, а не товар.** Продаёшь по-прежнему систему с подпиской, на созвоне.

## Условие

Фраза «уже собрал» должна быть правдой. Нужен один шаблон на нишу, куда подставляются название, город и телефон. Если демо ещё нет, замени вторую строку:

```
Могу за вечер собрать для «[Название]» сайт и показать. Платить не нужно, пока не понравится. Собрать?
```

Это слабее, но честно.

## Если сайт у них уже есть

Хук «сделал сайт» тут мёртв (твоё же решение), поэтому заходим через потерю. Факт должен быть реальным — минута на лида, чтобы открыть сайт с телефона.

```
Здравствуйте! Это [Имя]. Смотрел в 2ГИС [стоматологии] в [городе], зашёл на ваш сайт с телефона: [нет кнопки записи / не открывается прайс / грузится 8 секунд].

Собрал вариант под «[Название]», где это исправлено. Показать?
```

## После ответа

1. **Ответил «да»** — реагируй в течение 5 минут. Шли один скриншот первого экрана с их названием и пиши: «Остальное покажу за 10 минут по видео. Сегодня вечером или завтра утром?»
2. **Молчит сутки** — один дожим: «Показать сайт или не актуально?» Дальше звонок, а не третье сообщение.
3. **Текст не трогай до 100 отправок** (правило Хормози), потом меняй по одному элементу.

По объёму я бы начал с 20–30 первых сообщений в день с номера, с паузами и разным текстом — это перенос лимитов из твоей TG-методички, для WhatsApp я их не проверял.
