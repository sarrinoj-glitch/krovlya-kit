# Правила для Claude Code в этом репозитории

Репозиторий — набор для холодных продаж кровельным компаниям: лиды из 2ГИС, рассылка в WhatsApp, сайт по шаблону, презентация, CRM. Порядок работы описан в `PLAYBOOK.md`, накопленный контекст — в `memory/` (начни с `memory/MEMORY.md`).

## Язык
Отвечай по-русски, коротко: вывод, потом детали. Когда есть развилка — дай рекомендацию и одну строку «почему».

## Факты и цифры
- На сайте и в презентации только то, что можно проверить: карточки 2ГИС и Яндекс Карт, слова владельца компании. Стаж, число объектов, гарантии, сроки и отзывы не придумывай. Нет данных — убери блок.
- Каждая цифра — это факт с источником, условие самого продавца или допущение, которое так и названо. Источники и допущения записывай в README сайта.
- Отзывы: только настоящие, короткая цитата с именем и датой и ссылка на карточку.
- Фото — только с объектов самой компании (из её карточек или присланные владельцем).

## Сайт
- Сайт собирается командой `python3 site-template/make_site.py site-template/companies/<slug>.json`. Тексты меняются в JSON, а не в HTML.
- Дизайн шаблона не «улучшай»: меняется содержимое, а не вёрстка.
- Проверяй результат в браузере на ширине 1440 и 390: нет ошибок в консоли, нет битых картинок, нет горизонтальной прокрутки, калькулятор открывает WhatsApp компании.
- Пока владелец компании не принял сайт, в `<head>` остаётся `noindex`.
- Каждый сайт публикуется в своём репозитории на GitHub Pages. Из России `*.vercel.app` открывается нестабильно.

## Рассылка
- Сообщения отправляет человек, руками. Не предлагай программы для рассылки и не отправляй сообщения сам.
- Лимит новых чатов в день и правила из `docs/02-бан-в-whatsapp.md` не ослабляй.
- В первом сообщении нет ссылок, цены и ложного «личного опыта». Фраза «уже собрал сайт» допустима, только если сайт действительно собран.

## Продажа
- Продаём заявки и систему, а не «сайт»: сайт — приманка и часть системы (`memory/project_ai_clinic_saas.md`).
- Цены, сроки, дефицит и гарантии в презентации задаёт владелец репозитория. Не меняй их без его слова и не добавляй обещаний, которые некому выполнять.

## Чего в репозитории быть не должно
Ключей и паролей, материалов других клиентов, всего, что под соглашением о неразглашении, личных данных владельца.
