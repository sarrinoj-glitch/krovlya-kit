Строит рекуррентный SaaS («система») для локального бизнеса РФ по модели Kai Stone / dreamofmike (Stone Systems): сайт + ИИ-агенты + автоматизации, продаётся через холодный звонок + WhatsApp + видео-встречу (one-call close).

**Две ниши (зафиксированы):** натяжные потолки (объём, легко, владелец сам берёт трубку) и стоматологии (~2k контактов, сложнее — гейткипер-админ + у них уже есть сайт).

**Продукт = два ИИ-агента, один мозг в двух режимах, MVP текстовый без голоса:**
- ИИ-администратор (реактивный): отвечает в WhatsApp/Telegram 24/7, квалифицирует, записывает, перехватывает пропущенные звонки → мгновенный WhatsApp.
- ИИ-ассистент (проактивный): дожим незаписавшихся, реактивация базы, напоминания (анти-no-show), сбор отзывов на Яндекс/2ГИС; тоже квалифицирует и гонит по скрипту продаж.
Ложится на архитектуру из ~/Desktop/.claude/rules (Orchestrator/Claude, Wazzup24, Supabase conversations/messages/revival_queue, Next.js/Vercel).

**Решения по позиционированию (ОТВЕРГНУТЫЕ варианты не предлагать заново):**
- Продавать «поток пациентов / не теряешь заявки», НЕ «сайт» (иначе клиент сравнивает с разовой покупкой и режет цену).
- Цена выше стартовых 9 900: натяжные ~19 900; клиники 25–50к или гибрид (разово за сайт + подписка).
- Опенер для клиник: НЕ «бесплатный аудит» (запалён, звонят 30 раз/нед) — заход «тайный пациент» («был вашим пациентом, не смог дозвониться/записаться»).

**Артефакты в ~/Desktop/MyTests:** BLUEPRINT_1_KaiStone_USA.md, BLUEPRINT_2_DreamOfMike_Russia.md.

**Why:** активно строящееся направление (GTM + продукт), переживает сессии, не выводится из кода.
**How to apply:** при возврате к теме опираться на эти решения; не предлагать снова аудит-опенер, низкую цену 9.9к или рамку «продаём сайт» — отвергнуты. Соблюдать [[feedback-no-local-server]] (билд на Vercel). См. [[user-role]].
