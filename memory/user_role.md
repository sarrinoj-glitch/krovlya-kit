User is a developer/founder building landing pages and selling them via cold call. Primary market: Moscow.
Tested both dental clinics and roofing companies as target segments — uses 2GIS scraper for lead lists.

Workflow: builds demo site → cold calls → shows demo as "уже готовый сайт под вас" pattern (Hormozi-style "ready gift").
Cycle: parser → CSV → calls → demo → follow-up.

Has small budget for tools (uses free/OSS where possible: parser-2gis, Vercel, Unsplash photos).
Comfortable with Next.js, React, Tailwind. Deploys to Vercel.

**How to apply:** When advising on offers, scripts, or product decisions — bias toward what's testable
in <2 weeks of cold calls, not toward long-term strategic plays. Show ROI per call, not per year.
