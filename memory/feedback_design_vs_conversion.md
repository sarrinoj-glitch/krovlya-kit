When building landings for cold-sales scenarios (Russian dental/medical especially), premium animations
and effects (aurora, sparkles, 3D tilt, magnetic buttons, parallax) **do not equal conversion**.

**Why:** User explicitly stopped me mid-build when I was adding more magic mcp effects and said
«дизайн такого сайта не продает». The clinic owner he calls cares about: trust signals, fixed prices,
multiple forms, social proof with real numbers, document scans, sticky CTA — not "wow design".

**How to apply:** When user says "premium" + "selling tool" — default to COMBO mode:
- Keep restrained premium aesthetic (clean palette, Unbounded/Manrope, soft shadows, pill buttons)
- Layer 7+ conversion mechanisms on top: countdown promo banner, comparison table, interactive
  cost calculator, case study with invoice/cert chips, multiple inline mini-forms, sticky mobile CTA,
  floating WhatsApp, doc/cert gallery
- Tone down loud generic AI patterns (aurora backgrounds, sparkles, oversized italics) — they signal
  "AI-generated" and lower trust

For ARIUS dental landing specifically: structure was the right call — KEEP it (PromoBanner →
TopBar → Nav → Hero → CertBar → UnderKey → Comparison → Pricing → Calculator → CaseStudy →
Advantages → Process → Doctors → Reviews → Certs → FAQ → CTA → Footer). Don't redesign by removing
sections, only by adjusting visual surface.
