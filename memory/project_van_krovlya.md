`~/Desktop/MyTests/van-krovlya` — копия проекта `~/Desktop/LipetskCrovlya`, переделанная 06.10.2026 под ООО «Ван» (лид из `roofing_krasnodar_150.csv`, карточка https://yandex.ru/maps/-/CXe8aC4N). Одна страница `index.html` на базе **v3** (белый первый экран со скролл-анимацией крыши, кадры в `frames/` и `frames-sm/`), фото из карточки компании в Яндекс Картах — `assets/van/`. Первый вариант на базе v4 пользователь отклонил («не этот, там есть другой, v2 или v3, со скролл-анимацией») — лежит как `variant-v4.html`. Опубликован 06.10.2026 на GitHub Pages: https://sarrinoj-glitch.github.io/van-krovlya/ (репо `sarrinoj-glitch/van-krovlya`, публичный; `.gitignore` пускает в него только файлы сайта). В `<head>` стоит `noindex` — демо до согласования с владельцем.

Пользователь просил «чисто названия поменять», но после вопроса выбрал «переписать под „Ван“»: компания делает плоскую кровлю (наплавляемую, мембранную) плюс эвакуатор и погрузчик, а оригинал — скатные крыши со своим производством. Все факты на странице — из карточек 2ГИС и Яндекс Карт; источники и список допущений («за м²» у цен, шаги работы) записаны в `README.md` проекта, заметки сессий — в `_notes/`.

**Why:** копия сделана, чтобы показывать сайт конкретному лиду из рассылки («reference-telegram-outreach» (заметка не вошла в репозиторий)); оригинал — боевой сайт другого клиента.
**How to apply:** у папки свой репозиторий; не подключать её к репозиторию `sarrinoj-glitch/pc-agency-osman` и Vercel-проекту `lipetsk-krovlya` — выкладка затрёт сайт оригинала. Заметки по «Ван» не писать в `~/Desktop/липецкхран`. Новые факты о компании — только из карточек или со слов владельца ([[feedback-no-invented-numbers]]). Для показа в России — GitHub Pages, не Vercel ([[reference-vercel-cli-via-deno]]). Проверка страницы — headless Chrome по `file://` ([[feedback-no-local-server]]).
