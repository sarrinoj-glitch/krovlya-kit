Каждая цифра в материалах для клиента (презентации, офферы, калькуляторы) должна быть одного из трёх типов, и тип должен быть виден: **факт** (с источником), **норма пользователя**, **явное допущение** (помечено и проверяется).

**Why:** 30.09.2026 в другом проекте пользователь спросил «18–36 тёплых B2B-контактов — это вообще что? откуда?» — цифра была выдумана (5–10 % от заходов в бота, без основания), пришлось убирать. Пользователь не может защищать перед клиентом цифры без основания.

**How to apply:** перед тем как вписать число, спроси себя «на чём оно держится?». Если только на моей оценке — либо не писать, либо подписать «допущение, проверяем в пилоте». Не приписывать нормы аудитории презентации. Связано: [[feedback-communication-style]], «project-magomed-autofunnel» (заметка не вошла в репозиторий).
