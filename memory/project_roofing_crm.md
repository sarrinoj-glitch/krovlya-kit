Рассылка по 642 кровельным лидам из 2ГИС ведётся втроём: менеджеры **Ильяс, Зураб, Тимурлан**.

- **Google Таблица «CRM кровельщики»** (в Google Диске пользователя): https://docs.google.com/spreadsheets/d/1EagcNXcXaz74XoXbMPuaW9bJBWp_0Ybcr5KP18rTTb0/edit — пользователь 06.10.2026 попросил «перенести всё в гугл таблицы». Листы: Сводка, Сегодня, Канбан, Лиды (единственный рабочий), по листу на менеджера, Справка. Собирается скриптом `~/Desktop/MyTests/crm-krovlya/build_crm_xlsx.py` из списка лидов страницы → `.xlsx` → загрузка в Диск → «Сохранить как таблицу Google».
- **Страница-очередь** https://sarrinoj-glitch.github.io/wa-queue-krovlya/ (`~/Desktop/MyTests/wa-queue-krovlya`, один `index.html`): рассылка + воронка с канбаном, но отметки лежат в localStorage каждого браузера, общей базы нет — поэтому и переехали в таблицу.

Что выяснено при сборке таблицы (проверено в настоящих Google Таблицах): из xlsx нормально импортируются FILTER/SORT/ARRAY_CONSTRAIN/ENCODEURL, условное форматирование, закрепление, скрытые колонки; выпадающие списки импортируются только если список вписан прямо в правило (`"а,б,в"`), со ссылкой на диапазон другого листа — пропадают. LibreOffice эти формулы не считает, проверять надо в самих Таблицах.

**How to apply:** загрузка файла в Диск через Claude in Chrome работает, если перехватить `HTMLInputElement.prototype.click` и отдать файл в появившийся `input[type=file]`; в ячейку Таблиц текст печатается только после двойного клика. Доступ менеджерам к таблице пользователь выдаёт сам.
