# Кровля: лиды, рассылка, сайт по шаблону, презентация, CRM

Рабочий набор для холодных продаж кровельным компаниям. Один менеджер проходит весь путь: собрал лиды в 2ГИС → написал в WhatsApp → собрал компании сайт по шаблону → показал на созвоне презентацию → ведёт сделку в общей таблице.

## С чего начать

1. Прочитай [PLAYBOOK.md](PLAYBOOK.md): там семь шагов с командами.
2. Прочитай [docs/04-оффер-и-скрипт-звонка.md](docs/04-оффер-и-скрипт-звонка.md): что мы продаём и как об этом говорить.
3. Собери сайт-образец, чтобы убедиться, что всё работает:

```bash
python3 site-template/make_site.py site-template/companies/van.json
```

Результат появится в `site-template/sites/van/`. Открой `index.html` в браузере.

## Что нужно на компьютере

- Python 3 и два пакета: `pip install pillow openpyxl`
- git и [GitHub CLI](https://cli.github.com/) (`gh`) — для публикации сайтов
- Chrome
- Желательно [Claude Code](https://claude.com/claude-code): открой в нём эту папку, правила в `CLAUDE.md` он прочитает сам. С ним шаг «собрать сайт под компанию» занимает минуты: дай ссылки на карточки компании в 2ГИС и Яндекс Картах и попроси заполнить JSON по образцу `van.json`.

## Главные правила

1. **Ничего не выдумываем.** На сайте и в презентации только факты из карточек компании и слова её владельца. Нет данных — нет блока.
2. **Пишем руками.** Никаких программ для рассылки. Лимит — 15 новых чатов в день с номера.
3. **«Уже собрал сайт» — только если собрал.** Иначе пишем «могу собрать за вечер».
4. **Продаём заявки, а не сайт.** Сайт входит в систему бесплатно.
5. **Сайт закрыт от поиска**, пока владелец компании его не принял.
