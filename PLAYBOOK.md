# Порядок работы

Семь шагов от пустого списка до сделки. Команды запускаются из корня репозитория.

## 1. Собрать лиды в 2ГИС

Нужен [parser-2gis](https://github.com/interlark/parser-2gis). Рабочая команда и подводные камни — в [memory/reference_parser_2gis.md](memory/reference_parser_2gis.md). Коротко:

```bash
parser-2gis -i "https://2gis.ru/krasnodar/search/кровельные работы" -o leads/raw/roofing_krasnodar_raw.json -f json \
  --chrome.headless no --chrome.disable-images no --parser.max-records 500
```

- Окно браузера не скрывать и картинки не отключать: иначе 2ГИС отдаёт пустой результат.
- Формат только JSON.
- Рубрика конечна: в самом Краснодаре кровельщиков около 80, остальное добирается краем и другими городами.

Сырые выгрузки кладутся в `leads/raw/`, дальше их чистят скрипты:

```bash
python3 leads/build_roofing_krasnodar.py    # один город с пригородами → leads/roofing_krasnodar_150.csv
python3 leads/build_roofing_cities.py       # много городов, без повторов с первым списком → leads/roofing_cities_500.csv
```

Скрипты убирают дубли и филиалы, отделяют подрядчиков от магазинов и ставят приоритет: **A** — нет сайта, **B** — сайт есть, отзывов мало, **C** — остальные. Под свой город поправь списки в начале скрипта (пригороды, регионы).

## 2. Собрать страницу-очередь

Страница показывает лидов по одному: готовый текст, кнопка «Открыть WhatsApp», отметка «Отправлено».

```bash
cd queue && python3 build_queue.py ../leads/roofing_krasnodar_150.csv ../leads/roofing_cities_500.csv
```

Опубликуй `queue/index.html` в своём репозитории на GitHub Pages (как в шаге 5) и открой с телефона.

Отметки на странице хранятся в браузере, у каждого свои. Общая картина ведётся в таблице из шага 3.

## 3. Завести общую таблицу

```bash
python3 crm/build_crm_xlsx.py     # → crm/CRM кровельщики.xlsx
```

1. Загрузи файл в Google Диск и открой.
2. «Файл → Сохранить как таблицу Google».
3. Выдай доступ менеджерам.

Листы: «Сводка» (цифры), «Сегодня» (дела команды), «Канбан», «Лиды» (единственный рабочий лист), по листу на менеджера, «Справка». Имена менеджеров задаются в начале `build_crm_xlsx.py`.

Что проверено в настоящих Google Таблицах: формулы FILTER, SORT, ARRAY_CONSTRAIN и ENCODEURL из файла xlsx работают; выпадающие списки переносятся, только если список вписан прямо в правило.

## 4. Рассылка

Тексты и правила: [docs/01-первое-сообщение.md](docs/01-первое-сообщение.md), [docs/02-бан-в-whatsapp.md](docs/02-бан-в-whatsapp.md).

- Отдельная сим-карта, WhatsApp Business с заполненным профилем, номер «пожил» неделю-две.
- 10–15 новых чатов в день, руками, в рабочее время. За две недели можно дойти до 30–40.
- Сначала приоритет A (без сайта) с WhatsApp в карточке.
- Без ссылок в первом сообщении. Один дожим через сутки, дальше звонок.
- Ответил «да» — отвечай в течение пяти минут и зови на показ.

После каждой отправки: в таблице на листе «Лиды» поставь этап «Отправлено», себя в «Менеджер» и дату.

## 5. Собрать сайт под компанию

Сайт делается для того, кто ответил, или заранее для самых перспективных.

**5.1. Собери факты.** Открой карточки компании в 2ГИС и Яндекс Картах и выпиши: название и юрлицо, адрес, телефоны, график, рейтинг и число оценок, с какого года карточка, услуги и цены, способы оплаты, о чём пишут в отзывах, одну короткую цитату с именем и датой. Скачай 8–12 фото объектов.

**5.2. Подготовь фото.**

```bash
cd site-template
python3 tools/prep_photos.py ~/Downloads/фото-компании assets/<slug>
```

**5.3. Заполни JSON.** Скопируй `companies/van.json` в `companies/<slug>.json` и замени тексты. Структура жёсткая: четыре подписи под анимацией, четыре услуги и пять вкладок, три темы отзывов, шесть шагов. `&nbsp;` — неразрывный пробел, ставится после предлогов и перед единицами.

**5.4. Собери и проверь.**

```bash
python3 make_site.py companies/<slug>.json      # → sites/<slug>/
```

Открой `sites/<slug>/index.html` на компьютере и в режиме телефона. Пройди калькулятор до конца: он должен открыть WhatsApp компании.

**5.5. Запиши источники.** В `sites/<slug>/README.md` перечисли, откуда каждый факт и что является допущением. У «Ван» допущения такие: «за м²» у цен (в карточке единицы нет), шесть шагов работы (типовой порядок), описания технологий.

**5.6. Опубликуй.**

```bash
cd sites/<slug>
git init -b main && git add -A && git commit -m "Сайт"
gh repo create <slug>-krovlya --public --source=. --push
gh api -X POST repos/<твой-логин>/<slug>-krovlya/pages -f 'source[branch]=main' -f 'source[path]=/'
```

Через минуту сайт откроется на `https://<твой-логин>.github.io/<slug>-krovlya/`.

**5.7. Второй вариант первого экрана (по желанию).** Тёмное слайдшоу из фото вместо анимации:

```bash
python3 tools/make_v4.py companies/<slug>.json    # → sites/<slug>/v4.html
```

Тексты для него лежат в JSON компании в разделе `"v4"`: фото для слайдов, четыре всплывающие карточки, три строки с галочками. Пример — `companies/sds.json`.

**Если данных мало.** Блоки без фактов не выводятся: уберите из JSON раздел `reviews`, фото в `services` или поставьте вариантам калькулятора `min` и `max` равными 0 — тогда вместо суммы будет заявка. Если владелец репозитория велел показать сайт «с заглушками», добавьте `demo_note`: вверху появится полоса о том, что цены и фото стоят для примера (так сделаны `krt.json` и `krd.json`).

**Что знать про шаблон**
- На первом экране анимация скатной крыши с металлочерепицей. Для компании с плоскими кровлями это неточно: скажи об этом сам и предложи заменить после оплаты. Кадры лежат в `frames/` (121 штука) и `frames-sm/` (то же для телефона).
- Заявки из калькулятора уходят в WhatsApp самой компании.
- В `<head>` стоит `noindex`. Убирается, когда владелец принял сайт.

## 6. Презентация для созвона

Образец — `kp/index.html` (и PDF рядом). Скопируй, замени факты компании и опубликуй рядом с сайтом в папке `kp/`.

Что меняется под компанию:
- обложка: название, город, цифры из карточек;
- «Ваша ситуация» и «Что мы изучили»;
- ссылка на собранный сайт и список «что доделаем вместе»;
- пример диалога ассистента и пример окупаемости — пересчитай по ценам этой компании;
- подпись и дата «цены до…».

Что не меняется без слова владельца репозитория: тарифы (60 000 ₽ разово / 19 990 ₽ в месяц / 199 900 ₽ за год), гарантия, бонусы, «первым пяти — цена навсегда».

В блоке окупаемости три поля: на созвоне спроси цифры у клиента и впиши, расчёт появится сразу.

Разбор презентации по Хормози: [docs/05-разбор-презентации-по-хормози.md](docs/05-разбор-презентации-по-хормози.md).

## 7. Созвон и ведение

Оффер и скрипт с ответами на возражения: [docs/04-оффер-и-скрипт-звонка.md](docs/04-оффер-и-скрипт-звонка.md).

1. Покажи сайт с экрана и попроси открыть с телефона.
2. Спроси три цифры и впиши в блок окупаемости.
3. Покажи тарифы, назови гарантию.
4. Договорись о следующем шаге с датой.

После созвона в таблице: этап, дата следующего контакта, заметка. Лист «Сегодня» покажет, кому пора написать.

**Прежде чем обещать.** Презентация обещает перехват пропущенных звонков, напоминания после сметы и сбор отзывов. Убедись, что это есть кому делать, пусть и вручную на первых клиентах.
